# HACKER PROTOCOL: CYBER WORLD

A mobile-first 3D cyberpunk open-world prototype by **NATIONVK**.

## Current prototype (v0.1.0)
- 3D lab blockout scene
- Character movement, sprint and jump
- Third-person / first-person camera toggle (Page Up)
- Workstation interaction (E)
- Fictional node-sequence hacking puzzle
- Godot Android export preset

## Controls
- WASD: move
- Shift: sprint
- Space: jump
- Mouse: look (click the game window to capture)
- E: interact with workstation
- Page Up: toggle camera
- Esc: release mouse

## Build
Open this folder in Godot 4.4.1 or compatible Godot 4.x with Android export templates and Android SDK configured. Select the Android preset and export a debug APK.

The GitHub Actions workflow at `.github/workflows/build-cyber-world.yml` attempts the Android export and uploads the APK as an artifact.

## Scope and safety
All hacking is fictional, puzzle-based simulation contained inside the game. This prototype is not a real network intrusion tool.
